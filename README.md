# 🇪🇸 Español

## 📌 Sobre el proyecto

**GC Landing Page** es una página web desarrollada como práctica académica para la asignatura de **Lenguaje de Marcas**, dentro del ciclo formativo de Desarrollo de Aplicaciones Multiplataforma (DAM).

El proyecto consiste en diseñar y maquetar una landing page para *Gallumbos Ciruelo*, una marca ficticia de ropa interior masculina con una identidad desenfadada y un estilo visual moderno.

El objetivo principal es poner en práctica los conocimientos de HTML5 y CSS3, trabajando la estructura de una página web, la organización de sus contenidos y la adaptación del diseño a diferentes dispositivos.

## 🧩 Secciones de la web

- **Cabecera y navegación:** menú con enlaces internos para desplazarse por las distintas secciones.
- **Portada principal:** presentación de la marca y botones de llamada a la acción.
- **Catálogo de productos:** tarjetas para tres modelos ficticios, con sus nombres, precios y apartados desplegables con información adicional.
- **Reseñas:** sección con opiniones ficticias de clientes.
- **Sobre nosotros:** presentación de la filosofía y personalidad de la marca.
- **Destacados:** bloques de contenido que refuerzan la identidad de la página.
- **Preguntas frecuentes:** preguntas y respuestas desplegables mediante elementos HTML.
- **Formulario de contacto:** formulario maquetado para practicar la creación y personalización de campos.
- **Pie de página:** apartado final que completa la estructura de la web.

## 🛠️ Tecnologías utilizadas

### HTML5

HTML se utiliza para construir la estructura y organizar el contenido de la página.

Durante el desarrollo se trabajan conceptos como:

- Estructura básica de un documento HTML.
- Etiquetas semánticas como `header`, `nav`, `main`, `section` y `footer`.
- Títulos, párrafos y enlaces.
- Navegación interna mediante identificadores.
- Elementos desplegables con `details` y `summary`.
- Formularios y campos de entrada.

### CSS3

CSS se utiliza para definir el diseño visual y la distribución de los elementos.

Se trabajan los siguientes aspectos:

- Selectores y clases.
- Variables CSS para reutilizar los colores.
- Márgenes, rellenos, bordes y dimensiones.
- Tipografías y colores.
- Flexbox y Grid para organizar el contenido.
- Personalización de tarjetas y botones.
- Efectos `hover` y animaciones.
- Media queries para adaptar la web a diferentes tamaños de pantalla.
- Preferencias de movimiento reducido.

## 🎨 Diseño e identidad visual

La página utiliza una estética oscura con tonos morados y detalles en neón para crear una identidad visual reconocible.

La combinación de colores y el tono informal de los textos buscan dar personalidad a la marca ficticia y mantener una presentación coherente en todas las secciones.

## 📱 Diseño adaptable

Se han incorporado media queries para adaptar la distribución de los elementos a distintos tamaños de pantalla, incluyendo ordenadores, tabletas y móviles.

El objetivo es mantener una navegación clara y una presentación ordenada independientemente del dispositivo utilizado.

## 📁 Estructura del proyecto

```text
GC-Landing-Page/
│
├── index.html
├── README.md
│
└── css/
    └── style.css
```

Esta organización permite separar la estructura HTML de los estilos CSS y facilita el mantenimiento del código.

## 🚀 Cómo ejecutar el proyecto

1. Clona o descarga este repositorio.
2. Abre la carpeta del proyecto.
3. Abre `index.html` en un navegador web.
4. Navega por las secciones y prueba la página en diferentes tamaños de pantalla.

No es necesario instalar dependencias para visualizar la versión estática.

## ⚠️ Limitaciones

Este proyecto es una práctica de maquetación web, no una tienda online funcional.

No incluye carrito de compra, procesamiento de pagos, base de datos, gestión de usuarios ni envío real del formulario de contacto. Tampoco dispone de backend.

El alcance se centra en el uso de HTML5 y CSS3 para construir y presentar una página web.

## 🎯 Objetivos de aprendizaje

- Comprender la estructura de una página web mediante HTML.
- Separar el contenido de los estilos.
- Utilizar clases y variables CSS.
- Organizar la información en secciones y tarjetas.
- Crear enlaces de navegación interna.
- Practicar Flexbox, Grid y media queries.
- Mejorar la presentación mediante efectos visuales.
- Aplicar conceptos básicos de accesibilidad y diseño adaptable.
- Organizar los archivos de un proyecto web.

## 💡 Conclusión

GC Landing Page representa una primera aproximación práctica al desarrollo de interfaces web dentro de mi formación en DAM.

A través de este proyecto, he trabajado la estructura de una página, la organización de sus contenidos y la aplicación de estilos para conseguir una presentación coherente y adaptable.

El repositorio forma parte de mi portfolio académico y refleja mi proceso de aprendizaje con HTML5 y CSS3.

# 🇬🇧 English

## 📌 About the project

**GC Landing Page** is a website developed as an academic assignment for the **Markup Languages** module of the Multiplatform Application Development (DAM) programme.

The project consists of designing and building a landing page for *Gallumbos Ciruelo*, a fictional men's underwear brand with a playful identity and a modern visual style.

The main goal is to apply HTML5 and CSS3 fundamentals while working on webpage structure, content organization and responsive design.

## 🧩 Website sections

- **Header and navigation:** a navigation menu with internal links to the different sections.
- **Main landing section:** an introduction to the brand with call-to-action buttons.
- **Product catalogue:** cards for three fictional products, displaying their names, prices and expandable details.
- **Customer reviews:** a section featuring fictional customer feedback.
- **About us:** an introduction to the brand's identity and philosophy.
- **Highlights:** content blocks that reinforce the brand's personality.
- **Frequently Asked Questions (FAQ):** expandable questions and answers built with HTML elements.
- **Contact form:** a form layout created to practise building and styling input fields.
- **Footer:** the final section completing the webpage structure.

## 🛠️ Technologies used

### HTML5

HTML is used to build the webpage structure and organize its content.

The project covers concepts such as:

- Basic HTML document structure.
- Semantic elements such as `header`, `nav`, `main`, `section` and `footer`.
- Headings, paragraphs and links.
- Internal navigation using element IDs.
- Expandable content with `details` and `summary`.
- Forms and input fields.

### CSS3

CSS is used to define the visual design and layout of the page.

The main concepts include:

- CSS selectors and classes.
- CSS variables for reusable colour values.
- Margins, padding, borders and dimensions.
- Typography and colours.
- Flexbox and Grid for content layout.
- Custom styling for cards and buttons.
- Hover effects and animations.
- Media queries for different screen sizes.
- Reduced-motion preferences.

## 🎨 Design and visual identity

The website uses a dark background, purple tones and neon accents to create a distinctive visual identity.

The colour palette and informal copy help establish the personality of the fictional brand while keeping the design consistent across all sections.

## 📱 Responsive design

Media queries have been included to adapt the layout to different screen sizes, including desktop computers, tablets and mobile devices.

The goal is to maintain clear navigation and an organized layout across devices.

## 📁 Project structure

```text
GC-Landing-Page/
│
├── index.html
├── README.md
│
└── css/
    └── style.css
```

This structure separates HTML content from CSS styling, making the code easier to understand and maintain.

## 🚀 How to run the project

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Navigate through the sections and test the layout at different screen sizes.

No additional dependencies are required to view the static website.

## ⚠️ Limitations

This project is a frontend layout exercise, not a fully functional online store.

It does not include a shopping cart, payment processing, a database, user management or a working contact form. There is no backend implementation.

The scope focuses on using HTML5 and CSS3 to structure and style a webpage.

## 🎯 Learning objectives

- Understand webpage structure using HTML.
- Separate content from styling.
- Use CSS classes and variables.
- Organize information into sections and cards.
- Create internal navigation links.
- Practise Flexbox, Grid and media queries.
- Improve presentation with visual effects.
- Apply basic accessibility and responsive design principles.
- Organize files within a web project.

## 💡 Conclusion

GC Landing Page represents a practical introduction to web interface development as part of my DAM studies.

Through this project, I have practised structuring a webpage, organizing its content and applying CSS styles to achieve a consistent and responsive layout.

This repository is part of my academic portfolio and demonstrates my learning process with HTML5 and CSS3.
